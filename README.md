# FeedbackPro – Customer Feedback & Reviews Analytics Platform

This project is a frontend-only SaaS-style customer feedback analytics dashboard built with HTML, CSS, and vanilla JavaScript. It includes a premium dashboard, review management, sentiment analysis, advanced insights, notifications, reports, demo auth, and LocalStorage-backed persistence.

## Demo authentication

Use the demo admin account below:

- Email: admin@feedbackpro.io
- Password: admin123

This is not secure production authentication; it is intentionally labeled as a frontend-only demo.

## Features

- Premium dashboard with KPI cards and charts
- Review form with star rating, validation, and LocalStorage persistence
- Review management with filtering, sorting, pagination, and CSV export
- Rule-based sentiment analysis with keyword highlights
- Advanced customer insights and recommendation cards
- Notification center and report generation
- Responsive dark/light theme and mobile layout
- Reset and restore demo data from LocalStorage

## Run locally

From this project folder, start a local server:

```bash
python3 -m http.server 8000
```

Then open:

- http://localhost:8000/login.html
